# Workflow: Idea Generation

Use when the creator asks for ideas or says "what should I make next?".

1. Read `games/INDEX.md` (what's been tried, what performed) and `ideas/IDEAS.md`.
2. If web access is available in Claude Code, look up what's currently trending on
   Roblox (top charts, rising games, popular themes on short-form video). Note trends,
   never copy specific games.
3. Generate 10 ideas mixing: proven structure + fresh theme + social twist + clip-worthy
   moment. Include at least 2 weird experiments.
4. Score each with the rubric in `game-design.md` §7 (6 criteria, 1–5).
5. Append to `ideas/IDEAS.md`: one row per idea (title, one-line pitch, structure,
   hook clip, score, build days estimate, status = idea).
6. Recommend the top 3 with one sentence each on why. Next command: `/new-game <idea>`.
