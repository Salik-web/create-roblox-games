# Workflow: Live Update

1. Read roadmap in `GDD.md`/`LAUNCH.md`, latest data review, player feedback the
   creator pasted.
2. Plan the update (`UPDATE_LOG.md` draft): headline feature, new content rows,
   fixes, balance changes, new monetized cosmetics/event items, codes. Add a mini
   BUILD_PLAN section "Update N".
3. Build with `build-phase.md` rules; data migrations if schema changes (bump Version).
4. Test regression checklist; ensure old player data loads.
5. Prepare: new thumbnail/icon variant, title tag "[UPDATE N]", description update
   notes, 3 clips plan, in-game "What's new" board text.
6. `save_place`; creator publishes; log in `UPDATE_LOG.md` with date.
