# Publishing & Growth

## Publish flow (creator clicks; you prepare everything)
1. Studio: File → Publish to Roblox (new experience) — creator does this.
2. Game Settings: name, description, genre, Max Players, avatar type (R15), Security
   (Studio API access for DataStores), private servers, allow copying OFF.
3. Creator Hub: Maturity & Compliance Questionnaire, audience, icon, thumbnails,
   passes/products (or via `open_cloud_invoke`), badges, social links on the game page
   (allowed on the page if eligible, never inside the game).
4. Test as a private/friends-only game once, then set Public.

## Title & description (discovery)
- Title: 1–4 words, genre signal + hook ("Escape the Cursed School"). Update tags
  like "[UPDATE 2]" or "[EVENT]" when relevant (no emoji spam).
- Description: first line = hook; then 3–5 bullet features; update notes; codes; group
  invite text. No links, no copyrighted names, no misleading claims.
- Search terms players would type; natural, not keyword-stuffed.

## Icon (most important asset)
- 512×512, one clear subject (character face/monster close-up), strong contrast, bold
  colours, readable at tiny size, no small text, consistent with game.
- Make 2–3 variants; use Creator Hub thumbnail/icon experiments if available to
  test which gets better CTR.

## Thumbnails
- 1920×1080, show the *action* and the *feeling*: chaos, a scare, a big reward,
  friends together. Short bold text (2–4 words) max. 3–5 thumbnails, best first.
- Source: staged in-Studio scenes with dramatic lighting + `screen_capture`; generate
  hero characters/props; creator finishes text in Canva. No fake gameplay.

## Free growth
- Short-form video: 15–30 s vertical clips (TikTok, YouTube Shorts, Instagram Reels):
  hook in the first 2 seconds, funny/scary moment, call to action ("game in bio").
  Record in Studio/Roblox with a clean HUD (add a Studio-only "hide HUD" toggle).
  Post 1–2 per day in launch week.
- Codes posted on socials; update logs; Discord/community (optional).
- Ask players to like/favorite after a good moment (once).
- Friends & classmates for initial plays (helps the algorithm get first data).

## Paid growth (later, with earnings)
- Sponsored experiences/ads in Ads Manager: start small, measure CTR and retention of
  ad traffic; only advertise games with good D1 (> ~15%). Reinvest a fraction of
  earnings, not savings.

## Launch-week rhythm
Day 0 publish → Day 1–2 fix bugs from real players → Day 3 thumbnail tweak if CTR low →
Day 5–7 first small update + codes → Week 2 review data (`workflows/data-review.md`).
